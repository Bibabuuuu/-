## 已确认范围与实行选择

复用run_buffer现有逆动力学/姿态反馈、局部IK路径、几何分担及接触场景，保持躯干固定。使用0.5 kg已核验有限工况、原μ/夹持/执行器参数。力矩饱和、重载极限和持续接触调参不作为主线。

Ruckig Community停车速度接口作为新增基线依赖，仅安装到项目venv，固定PyPI有CPython3.12 Windows二进制的0.19.4；不调用云接口/中间点、不使用Pro功能。网页最新文档版本0.19.7不等于安装包版本，按实际安装API核查。

最小增量：run_buffer允许可选参考提供者，默认完全保持；新参考从触发时观测速度/加速度出发，计划位置接管保持连续。底盘执行预先给定、独立于物体参考的制动命令。比较原零初始加速度S曲线与Ruckig，记录接管差异。

任务适配器在运行前对当前固定姿态分支建立局部IK路径及几何包络；触发时用候选轨迹检查相对行程、关节速度、全上身携物包络前行与空间预算。采样检查及显式工程余量不是全局安全证明。若偏好缓冲参考未通过，记录具体原因并用固定上身参考回退，不能将回退称为满足物体加速度要求或已证明全局不可行。

本轮“一次OTG参考生成＋现有高频关节/姿态反馈”不称为MPC或上层滚动反馈修正。后者需要下一阶段在相同任务约束下公平比较。

## 步骤与验收

1. 固定依赖版本/轮包哈希，核查实际速度停车API。独立比较静止初始加速度时Ruckig与现有解析S曲线；另核查非零初始加速度、终态、连续性、限制与拒绝条件。
2. 新增可选参考接口与记录；原固定/缓冲默认各运行一次，time/qpos/qvel/ctrl精确回归第十二小节。
3. 对匀速触发、加速中触发、较高速度或有效初始姿态等少量设置做原S/Ruckig配对；各方法同一底盘命令和触发前状态。增加狭窄空间拒绝/回退及关键半步长复核。物理完整运行初轮最多16次，含初版及最终默认回归各2次；曾发现旧模板准入条件不应作用于外部参考，已修正并安排最终回归。
4. 检查实际停车、物体加速度与朝向、参考接管、相对行程、几何包络、抓持、接触与数值质量；拒绝、回退、失败全部保留。不给“状态驱动”或“Ruckig”预设性能优势。

主要边界：理想模型状态；物体姿态固定；当前运动学支路的可达性；名义底盘预测与执行命令一致；没有真实传感器/全局可达域/动态障碍/主动躯干/MPC或硬件稳定性保证。底盘预测偏差的滚动修正留待有强基线后实施。

交付：新增基线源码、依赖与独立核查记录、有限仿真配对结果和中文报告；更新本计划及权威入口。

## 完成结果与证据

已安装并固定Ruckig0.19.4，官方Windows轮包哈希与PyPI一致，依赖写入项目requirements。三个零初始加速度速度值下，轨迹与原解析S曲线在浮点精度内一致；非零初始加速度及终态限制检查、498个mesh几何AABB包含性核查通过。

物理运行15次，未完成运行0次：前后默认回归4次，新增接口11次。15次均通过数值/接触/关节质量、原抓持门槛及底盘停车检查。新接口11次中9次满足示例物体加速度/姿态/空间指标；固定上身与窄空间回退两次超过0.8 m/s²示例门槛。4次默认回归与第十二小节time/qpos/qvel/ctrl逐点一致。4组S/R配对的触发前状态控制完全一致，底盘运动可比。源模型、原始runner及15次快照哈希全部核对。

匀速触发S/R物理峰值加速度均约0.7817 m/s²，无新增性能优势。加速触发时，原S参考加速度接管下降约0.6 m/s²，1 ms差分率约600、半步长约1200；Ruckig匹配观测加速度，差分率约5，两步长一致。但需前向相对行程约23.44 mm，实际峰值加速度约0.6918，高于原S包含触发边界的0.6001；不能宣称全面更优。两方法允许相同后向检查行程，原S短暂回缩约1.99 mm，避免不公平的前向单侧准入。

12.5 cm空间拒绝缓冲后，固定上身回退包络约12.005 cm、底盘停车和抓持通过，但物体峰值约1.0016 m/s²。0.5 m/s、0.75 s底盘制动本身需约18.75 cm，默认15 cm离线拒绝；物理配对显式另设22 cm。前伸姿态和缩短当前检查行程亦有有限通过/拒绝案例，不作全局可达性结论。

新发现两个待解决边界：观测速度与旧命令不同，加速触发时参考速度相差约−0.0002284 m/s，故没有证明完整C²接管；Ruckig调用约0.05–0.18 ms但整套候选准入约43–45 ms，未注入仿真时间，也不构成实时保证。原始initial_command_acceleration_jump字段是相对观测加速度的差，分析已另列相对旧命令左极限的速度/加速度差。早期两次匀速运行的模板配置占位与缺失候选NPZ如实记录，不修改历史或补造数据。
