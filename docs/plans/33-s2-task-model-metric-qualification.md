## 目标与简短方案核对

本节回答：现有名义模型能否执行二维转向制动，并提供足以比较后续停止决策的多类观测？它的作用是检验实验平台，不能直接证明避障策略、抓持改善或创新。

已确认：先仿真，Python＋MuJoCo；最终任务含底盘路线/速度选择、腰臂姿态与力矩/载荷协调、多指标稳定。S1的分层组织方式用于当前推进，具体规划/优化算法仍未冻结。硬件接口与实物标定资源未知，不阻塞名义模型的有限检查，也不据此推断真机性能。

可选实施：直接接入二维优化器，或先做最小执行/观测探针。前者会把执行器、模型、指标与规划失败混在一起；本节采用后者。复用已有研究模型、限jerk参考、逆动力学和抓持观测器，新增独立诊断入口，保留旧源码/模型哈希。目录未使用Git，本次按输入哈希和新增源码快照定位，不建立远程仓库。

本节无需补充硬件信息即可开始。普通参数沿用现有工况，新增小角度转向只检查方向和耦合，不视为能力上限。出现需改动接地模型、核心执行架构或新增重要依赖的证据时，先汇报，不扩大实现。

## 输入、输出与最小任务合同

输入：S1[首轮调查](../../outputs/robot-topic-study/s1-integrated-stop/联合制动路线与多指标稳定_首轮调查.md)、第26节原始模型/状态、默认接触设置、已有GraspObserver。

输出目录：`outputs/rby1-research/s2-qualification/`。本节维护任务合同、独立诊断源码与运行记录、紧凑原始状态/接触观测、结果说明与核查。已有观测沿用其元数据；新增量标注单位/坐标，不重构公共接口。

首版任务假设：抓取已完成的一类刚体载荷，差速底盘，上身保持供电；规划输入先用当前已知静态几何和状态，允许改变底盘二维路线和速度，最终进入静止持物。感知误差、动态障碍预测、VLA、液体/柔性内部动力学留待后续。

当前探针不放障碍，不自动选择路线。上身保持名义关节姿态，使用已知载荷惯性前馈和原接触设置，检查转向/制动及观测；不将简单执行探针当成拟研究联合控制器。

## 步骤与预算

1. 离线检查轮轴符号、坐标/单位、模型/状态哈希及旧指标定义；独立检查参考轨迹的差速非完整关系、直线退化、左右镜像、起止角速度/角加速度。
2. 独立诊断沿用约0.4 m/s、0.5 kg、限加速度0.5 m/s²、限jerk 5 m/s³。这些是历史名义/整形设置，不是损伤或硬件上限。±10°为对称方向探针，不称为避障动作或能力边界。保存状态实际时间3.501 s，初速按该状态核对，不冒称恰好触发瞬间。
3. 初轮最多4次物理运行：静止持物、直线停止、左转停止、右转停止。后三者使用同一保存状态；重建求解器，不称为完整检查点精确续跑。静止诊断另将速度清零，不与停止动作作优劣排名。
4. 若有方向/执行异常，保留数据并定位，最多补1次有判别力诊断；若正常，最多1次半步长复核转向。首轮总量上限6次，不扫描高速、质量或摩擦。先用短试运行走通加载—推进—保存—审计，再执行其余；短试运行计入预算。
5. 形成资格结论、边界及下一步。必要观测不可靠时限定主张，不无限调接触求解器。

## 验证与完成条件

- 参考：轮速/航向约定与非完整关系一致；参考满足不等于动力学满足。
- 执行：记录实际二维位置/朝向/速度、误差、轮地相对运动代理、支撑接触、底盘倾角、关节范围/速度、控制截断及自碰。原始量与数值容差分开；不凭运行完成即判定可执行。
- 稳定：物体世界线/角运动、手系相对位姿、每手接触力/力矩、接触保持与摩擦利用、停车后统一1秒观察。运动代理不等于材料点真实滑移；默认接触慢漂仍未解决。
- 动力学：核对接触合力/合力矩与物体Newton–Euler需求，说明离散/求解残差；交叉检查速度坐标。大残差先查定义，不直接归因于控制。
- 完成：明确最小任务与可用指标，说明二维执行到哪里、哪些量能进入下阶段、什么仍未知；可得有限通过或局部不通过，不要求解决任意障碍。
- 回退：旧源码/模型不改，失败数据保留。若必须改变核心模型/路线，停止扩大实现并提交证据。

### 第二轮：轮速执行修复（已授权实施）

用户收到首轮结果和“保持模型参数、补足速度/角速度跟踪”的建议后再次要求继续。本轮仍属于S2常规执行修复，不改变最终研究路线或模型参数。

候选是提高比例增益或增加积分。前者仍依靠持续误差提供抗阻力力矩，且增加瞬时刚度；本轮先选原轮速比例环加积分，显式处理控制截断时的积分累积。初始积分时间常数0.2 s，Ki=8/0.2=40，属于待检验控制整定，不是物理限值。若有明显响应问题，依据记录最多做一次有针对性的调整，不扫描参数。

复用原探针并增加默认关闭的可选补偿；旧实验绑定其已保存的源码快照，不用新版本重写旧证据。先做一次关闭功能的逐值回归，再运行左/右转和直线；正常时做半步长及静止保持复核。最多6次新物理，首轮6次单独保留；若候选失败，剩余预算优先诊断，不为凑满矩阵追加运行。上层路线选择、摩擦/轮几何修改、高速扫描仍不实施。

完成证据：关闭回归、同初态/参考/物理模型对照、轮速误差与积分/截断记录、转角及末态运动、接触与物体多指标，以及旧物理源码/模型冻结检查。结果放在本节输出目录的tracking子目录，后续在本记录更新，不另建小节计划。

第二轮中间证据：仅加积分使左转终点由6.153°改善到9.692°，但参考停止后1秒仍转0.889°、终点偏航速率约0.454°/s，不能以角度更近就宣布停稳。轮速误差已减小，原外层航向修正增益1.5/s较慢。因此本轮唯一一次定向调整选航向增益4/s，原轮速比例8和积分Ti=0.2 s保持不变；这是待验证整定，不是硬件能力值。为公开该参数并核验新版本默认关闭行为，增加一次同版本关闭回归，第二轮预算更新为最多7次。其余名额用于调整后左/右/直线及半步长；不追加静止扫描。保留第一次PI结果和源码快照，不将其覆盖。

进一步核对终态语义：PI＋航向增益4使角度约10.157°，但末态仍约0.314°/s；追赶预设10°造成参考停止后继续运动。±10°原为诊断参考，不是必须精确达到的工艺目标。急停终端应优先归零速度，记录实际终态误差，而不是继续追位置/朝向。新增可选终端模式：参考T后取消轮侧位置/航向追赶，清除运动阶段积分，保留零速反馈、原动力学/持物补偿与原限值。该模式不是自动避障，也不保证实际轨迹满足未来障碍，误差必须另行检查。

为验证这个任务语义修复并保留同版本默认关闭回归，第二轮最终预算最多9次：已有两次回归、两次未修复PI对照，共4次；新增最终版本回归、停止优先左/右/直线及左转半步长，共5次。此后不再扩展整定。增量是约20秒仿真计算的有针对性修复验证，不是参数网格。控制切换的力矩变化和物体受力必须一并记录，不因更快停下就声称稳定更好。
