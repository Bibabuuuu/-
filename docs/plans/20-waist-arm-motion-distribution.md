# 同一停止参考下的腰臂运动分配

- 状态：已完成；方案状态：已实现、已验证，限离线分配与两组名义物理对照。
- 授权：用户同意先用雅可比＋小规模QP建立腰臂运动分配，先离线计算及MuJoCo验证，比较相同轨迹下的腰固定与腰臂参与。
- 总体入口：[项目记录](../../outputs/robot-topic-study/双课题范围更新.json)；前序：[约束清理](19-constraint-cleanup.md)。当前目录仍无Git仓库，沿用源码/模型及当次路径快照。

## 目标与边界

复用现有状态驱动停止参考、实际底盘前向反馈映射、动力学跟踪、有限摩擦抓持和几何载荷分担。新增离线运动分配层：由共同物体位姿确定双手目标，同时求解双臂14关节，或躯干6＋双臂14关节。头、夹爪、底盘不参与这一运动学优化。

优先复用现有小型可行主动集QP，不新增求解器依赖。局部QP以双手位置/朝向误差为任务，惩罚按关节速度上限归一化的关节增量；用关节位置范围和数值步长边界限制迭代。速度上限用于实际停止轨迹的后续准入与执行核验，数值IK迭代步长不冒充物理速度。

碰撞在非线性FK、迭代步验收及独立采样中检查；本轮不承诺绕过碰撞寻找全局路径。关节路径保留现有插值接口，独立核查FK、共同抓持关系、范围、碰撞和解析导数，随后由现有控制器执行。所有参考求解使用独立MjData，不重置物理状态。

第一版仍只执行既有直线/固定物体朝向任务；这是对照范围，不是算法永久限制。腰部是否运动由同一个归一化运动代价决定，不强制腰部参与，不增加任意空间或物体阈值。

## 实施与验证

1. 新增运动分配模块，两种关节集合共用同一求解与拟合流程；旧执行模式默认不变。
2. 独立检查雅可比有限差分、QP约束/KKT、路径插值FK及双手抓持几何、关节范围与碰撞。原路径误差门槛不放宽。
3. 最多5次完整物理运行：原正常基线精确回归1次；0.4及0.5 m/s、底盘0.6 s制动各做腰固定/腰臂两次。两组各自的底盘和物体参考必须一致；载荷0.5 kg、接触、控制器、时窗均保持一致。
4. 比较物体加速度/姿态/滑移、跟踪误差、手臂与躯干分别的运动量/速度/范围余量、上身包络和底盘实际运动。求解失败、物理检查未通过和性能改善分开记录。

完成条件：模块在独立运动学检查及名义物理执行中可靠，或明确记录不可行/失败位置；对照支持的收益与代价如实给出。若新证据需要更换控制架构或接触模型，停止扩大实施，报告问题。

不做：新停止轨迹优化器、在线MPC、传感误差/延迟扫描、力矩饱和研究、真实硬件接口或论文创新宣称。离线耗时不作为在线实时性证明。

## 实现和证据

新增[motion_distribution.py](../../simulation/rby1/motion_distribution.py)，两种关节集合使用同一局部QP及7次多项式拟合，初始姿态精确锚定，输出q、dq/dx、d²q/dx²。执行层继续使用q̇=qₓẋ、q̈=qₓẍ＋qₓₓẋ²，由原逆动力学＋反馈控制跟踪；实际底盘前向反馈只改变坐标映射，不重置物体停止参考。

共同物体位姿和初始物体到双手变换确定双手目标。数值IK目标为双手任务残差加归一化关节增量：角度残差沿用0.25 m/rad尺度，正则化1e−5，归一化分母为各关节模型速度上限。0.12 rad为迭代信赖步长，80次为数值求解保护，不是新增物理能力限制。关节范围采用模型范围，碰撞数值门槛与原路径检查一致；实际定时参考及物理速度另查。没有单独给腰部优惠权重或要求它必须运动。

复用了原QP求解器、状态驱动停止参考、动力学与载荷分担。知识库只参考了“参考/实际状态分开”和“参考点/坐标系/时序独立核查”方法，没有迁入外部项目代码。没有新增依赖。仿真接口保留运行超时/掉落/路径保护，当前没有实机命令。

[独立检查](../../outputs/rby1-research/stage20/independent_checks.json)通过：20变量有活跃边界的QP与解析解一致；双手Jacobian的有限差分最大误差约3.01e−10。每组独立801点核查，腰固定/腰臂的最大位置残差7.54 μm/0.038 μm，共同双手相对位置误差3.17 μm/0.0042 μm，无非抓持穿透或越界；一二阶导数检查通过。路径准备耗时约百毫秒，仅为离线准备，不证明在线实时性。检查脚本开发时曾遗漏第二组开始前恢复测试数据，已修正测试隔离并重新通过；不是物理运行失败。

## 两组物理对照结果

共5次完整运行：旧正常基线回归1次、两个速度的腰固定/腰臂各1次。全部完成，现有模型检查、底盘跟踪与历史抓持诊断通过，无路径保护触发。回归的time/qpos/qvel/ctrl与第19小节逐点一致；两组对照的底盘、物体参考及预测相对位移逐点一致。

| 指标 | 0.4 m/s 腰固定 | 0.4 m/s 腰臂 | 0.5 m/s 腰固定 | 0.5 m/s 腰臂 |
|---|---:|---:|---:|---:|
| 手臂最大单关节运动 / ° | 4.542 | 0.516 | 18.245 | 1.880 |
| 躯干最大单关节运动 / ° | 0.0019 | 0.612 | 0.0023 | 2.175 |
| 手臂总关节运动量 / rad | 0.4991 | 0.0401 | 1.9528 | 0.1439 |
| 物体实际峰值加速度 / m/s² | 0.78108 | 0.78151 | 0.78216 | 0.78149 |
| 物体最大朝向误差 / ° | 0.05251 | 0.05252 | 0.06446 | 0.06446 |
| 原口径抓持相对位移 / mm | 0.789 | 0.779 | 0.878 | 0.765 |
| 上身前向包络 / cm | 13.286 | 13.374 | 19.862 | 19.921 |

手臂总关节运动量是制动开始后到6 s观察结束的各关节绝对变化累加，按100 Hz保存状态计算；下降91.97%/92.63%。这是关节运动指标，不是能耗、承载能力或物体稳定性提高92%。躯干角度为6个关节中单关节最大变化，不代表整个躯干整体转角。

腰臂参与后，手臂最小关节范围余量从0.6190/0.5385 rad变为0.6434/0.6434 rad。单次局部路径及两个工况不足以证明扩大了整体可达域。物体加速度和姿态几乎不变；抓持位移有小幅变化，不能据此声称普遍改善或真实物体无损。上身包络增加约0.88/0.58 mm，仍如实记录，不补设空间门槛。

底盘都使用原0.6 s参考；实际成对制动位置最大差约1.03/2.28 μm，速度最大差约1.91e−5/2.98e−5 m/s，未靠放宽底盘制动得到收益。两种运动分配从初始化启用，触发前实际物体位置差约0.060/0.074 μm；不能声称触发前物理状态逐点相同。
