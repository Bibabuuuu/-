# 相对微动来源：已有数据的几何分解

- 状态：已完成；方案状态：只读定位已实现、已验证。完整位姿补偿仍为候选，未改控制、接触设置或新增物理运行。
- 总体入口：[项目记录](../../outputs/robot-topic-study/双课题范围更新.json)；前置：[第27节](27-grasp-contact-baseline.md)及手坐标说明。当前仍无Git，以原始文件哈希与分析源码保留证据。

## 问题与范围

NoSlip3减小持续慢漂后，缓冲组手系相对位移模长更大，而且主要为z正向变化。需要判断它来自物体世界运动、手的位置变化、坐标轴转动，还是接触附近的真实几何相对运动。不能把一个物体参考原点的位移模长直接解释为滑落，也不能反过来把全部变化说成坐标假象。

复用第26节原设置和第27节NoSlip3各四组、1 kHz抓持/接触记录、约100 Hz保存状态、原关节路径与原参考日志。无新求解器/依赖。暂不分析新负载或外部障碍，不改变默认模型，不设计防滑反馈或增益。

## 已授权路线与验收

1. 原物体原点在手系的位移分为世界相对位移和手系旋转项，逐点验证闭合；另以初始手参考位置对应的物体固连虚拟点检查参考点选择的影响，仍保留相对旋转指标，不称真实接触点。
2. 独立MjData复放保存状态，以触发附近的实际基座姿态固定为几何参照，将手世界高度变化分为定时参考路径、实际关节相对参考的几何偏差、基座平移及基座朝向影响。冻结基座只是FK计算，不是物理反事实干预，不据此保证控制修正收益。
3. 在3.501 s按每个指垫当时的接触力加权初始接触位置定义对象/指垫固连参考点，随后检查同一组点的法向与切向分离，避免把每帧变化的接触序号当材料点。该指标仍是接触初始位置的几何对照，不冒充实时材料点跟踪或普遍滑移证书。与原1 kHz切向路程代理分开报告。
4. 统一8组时间窗3.501–4.401 s（保存状态实际时间，不伪称精确3.5–4.4），验证FK与已有高频相对位姿记录一致、平移/旋转/路径分解数值闭合、源文件不变，并用简单刚体解析例核对符号。
5. 输出逐手/逐指垫CSV、逐时序分解、通俗结论和最小后续建议。完成定位或明确无法分清的边界即可；不为获得控制改进而扩大实验。

## 当前状态

完成原设置/NoSlip3共8组、各91个保存状态的统一只读分析。输出1456行逐手时序、2912行逐指垫时序、16行逐手汇总与32行逐指垫汇总。保存状态FK与已有高频相对位姿记录最大差0，手高度拆分闭合，手系z拆分最大闭合误差约2.52e-17 m。三个解析例通过；开发时手写坐标旋转解析例的正负号错误已由自检发现并修正，不涉及物理数据。

## 主要结果

NoSlip3缓冲组左手3.501–4.401 s的手高度变化−0.020378 mm，可在指定FK参照下精确拆为：

| 项目 | 高度变化/mm |
|---|---:|
| 在触发时实际基座姿态上执行参考路径 | −0.005467 |
| 实际关节相对参考的几何偏差 | −0.002852 |
| 基座高度变化 | −0.002124 |
| 基座随后朝向变化 | −0.009935 |
| 合计 | −0.020378 |

同一参考路径放回原建模基座，手高变化仅约−2.15e-7 mm；第一项主要反映已倾斜基座上执行前伸的几何效应，不归咎于路径插值误差。基座俯仰从0.005213°变到0.006564°。这些是几何归因，不是已做的物理消融或可保证的控制收益比例。

相对z+0.023900 mm中，世界相对高度项+0.021533 mm、初始轴投影修正约+0.000000523 mm、随后手系转动项+0.002366 mm。物体世界高度仅+0.001155 mm，不能称其整体升高0.024 mm。

缓冲组初始接触位置固连参考点的切向相对变化峰值约0.026144 mm；1 kHz当前接触切向路程代理约0.030652 mm。该配对点仍在指垫切向投影范围内，保存时刻均有承载接触记录。因此剩余变化不能全归为坐标轴或物体原点选择；但这些指标仍不能独立区分真实材料点滑移、柔顺与局部接触运动。

原设置下同一较快底盘的缓冲/无缓冲两组物体世界下移接近（−0.138893/−0.138653 mm），手参考点却分别−0.019680/+0.001873 mm。原先相对下移指标的差异主要由手运动项贡献，不等于物体世界高度明显更稳定。

## 下一步候选及边界

已确认现有`world_x_feedback`只在一维路径映射中使用实际底盘前后位置/速度；实际底盘高度与朝向没有形成完整末端世界位姿目标补偿。建议保持原物体世界参考与抓持变换，先离线核查T_BH_des=inverse(T_WB_actual)×T_WO_des×T_OH，检查关节变化与几何闭合，再讨论有限在线对照。该标准坐标变换不作为创新，也不保证运行后自动消除微动；在线导数一致性/连续性、接触模型与多指标需另验。

本节无物理运行，旧模型、源文件及记录哈希不变；没有增加夹紧力、摩擦、力控或MPC。下一实施小节尚未启动。
