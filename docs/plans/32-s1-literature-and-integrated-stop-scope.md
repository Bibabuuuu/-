# S1：联合制动运动与持物稳定——文献和路线调查

- 状态：已完成。
- 方案状态：用户已明确最终目标并授权调查；本节只做资料核查、问题分解和技术路线比较，不实施新控制器或新仿真。
- 总体入口：[总体规划](../PROJECT_PLAN.md)。历史01–31属于前期探索，本文件是总体规划S1的具体计划。

## 授权与目标

用户明确：急停时初速较高、可用停止距离较短，根据障碍选择制动路线与速度控制，包含机械臂/躯干姿态及力矩分配，以多个数据评价末端稳定；实际能达到的程度继续调查。其余问题由助手自主调查。

据此，不能继续把“底盘曲线给定”当作唯一主任务，也不再要求在“减负荷”和“抓持稳定”之间二选一。最终目标已确认，算法、可验证范围、单篇贡献和性能程度仍待调查。

## 本节要回答的问题

1. 紧急/受控制动、稳定运输、移动双臂全身规划、共同持物力分配分别已研究到哪里，哪些工作已同时覆盖多项？
2. 底盘路径/速度、载荷运动、腰臂姿态和接触力矩如何划分变量与接口？联合优化或分层求解的适用条件、代价和已有证据是什么？
3. 现有Python＋MuJoCo平台可复用哪些模块，哪些能力尚未验证，特别是转向制动和多维耦合？
4. 多指标稳定评价哪些已有可用记录，哪些还缺可信观测/验证？
5. 在整体目标下，先做哪一个有判别力的研究增量，怎样组织后续小节而不一次实现全部模块？

## 调查路线与预算

先用CrossRef/arXiv多源检索及现有论文索引，辅以作者/出版社原文和官方代码。按“急停/可停止性”“移动操作稳定运输与避障”“双臂全身运动/力控制”组织查询；优先精读最接近的少量工作，再按缺项定向补充，不追求凑论文数量。首轮约4–6组查询、8–12项重点候选；若结果高度重复则停止扩展，若关键结论仍缺原文则明确保留。

题名/DOI/作者归并预印本与发表版本，保留阅读版本、精读范围、代码是否核实。检索失败、全文访问失败、仅摘要判断均记录；未获得的最终版不冒充已读。

技术路线比较只形成候选：全身联合预测控制、任务空间规划＋全身执行、成熟参考＋约束筛选/参考调整。不能先锁定MPC，也不能预设简单参数选择就是贡献。

输入：总体规划v0.2沿用的证据表及v0.3确认目标、用户本轮要求、既有文献/代码和第26–31节核验。输出：

- [本节结果目录](../../outputs/robot-topic-study/s1-integrated-stop/)：结构化文献/查询记录、覆盖矩阵、通俗路线调查说明。
- 一份后续阶段的推荐顺序、必要决策与风险；若资料不足，标注不足，不以文字升级成创新成立。

## 完成与停止条件

当能够逐项解释“目标由哪些模块组成、前作覆盖什么、现有基础到哪里、下一小节应检验哪个关键问题”时完成本轮调查。S1完成仅代表调查与路线候选可讨论，不代表最终技术路线或后续代码已获授权。

本轮不设未经依据的高速值、抓持安全阈值、真实误差/延迟，不新增力矩饱和扫描、感知/VLA系统或硬件实验。若联合规划路线显示显著工作量/平台能力缺口，写入总体规划并提出分阶段方案，不能自行把用户最终目标降为只降低加速度。
