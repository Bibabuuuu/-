## 调查与具体决策

Crossref/arXiv 与原始论文/机构来源发现：双臂载荷冗余和内部力已有研究；IROS 2023 Dio 等以 HQP 显式处理关节力矩/内部载荷，当前取得摘要与元数据；DLR Justin 的全身阻抗控制给出臂、躯干和底盘的冗余协调；Du 等双臂移动操作采用分层运动规划与预测导纳。必须区分动力学力矩优化、运动学姿态协调和位置/速度接口的导纳，不把所有 QP 称为同一种方法。

理论关键：固定机器人姿态和载荷总扳手时，双手的分担可变化，手臂关节负担可变；共同上游躯干的载荷映射受到总扳手约束，不能任意独立重分配。要改变共同躯干负担，需要改变姿态、加速度或总作用。先做雅可比/虚功数值核验。

实现选择：保留当前对称分担，新增一个 NumPy 小型严格凸 QP，只优化不改变载荷合力/合矩的五维内部扳手自由度，保持两手侧向合力为零。目标含归一化上肢力矩、握持点力矩与偏离原分配的正则项；约束为关节力矩、明确的分配变化边界、简化手部切向合力内接摩擦条件。用经典可行主动集求解，做独立 KKT/解析检查；不新增求解器依赖。

这只是文献思想的小型适配，不复现完整 HQP/WBC；不保证接触斑内完整扳手可实现，也没有腕力闭环。期望分配必须与实际接触反力、滑移、姿态等分别评价。不能只报优化目标下降。

躯干作用先采用离线初始姿态对照：改变少量躯干初始角度，用双臂 IK 保持相同世界握持位置/朝向；筛掉碰撞或限位候选，检查姿态如何改变关节需求。不是制动期间主动腰部轨迹优化。这样能先区分受力分担与姿态变化两个机制，避免一次加入完整 MPC。

## 输入与步骤

复用当前已验证场景、0.4 m/s / 0.6 s 底盘制动、A=0.78/J=5 分段参考、1 kg载荷与原判据。

1. 保存检索、DOI 元数据、原文阅读范围和访问失败；不以转述冒充全文。
2. 构造保持物体扳手的内部自由度，检查合力/矩、共同躯干不变性和 QP 最优性。功能关闭精确复现第九小节。
3. 载荷偏心通过原三块长方体质量分数从 [0.8,0.1,0.1] 改为 [0.6,0.3,0.1]，总质量及外形不变，重新计算质心与惯量。不是任意修改质心。
4. 代表物理条件：原姿态居中载荷、原姿态偏心载荷、一个通过 IK/碰撞筛选的替代姿态。各做对称/QP、固定/缓冲，共最多12次；偏心对称/QP先各做静止持物检查2次；关键偏心缓冲配对半步长2次。总数先限定16次，失败保留，静态不合格不当作制动失效。
5. 比较实际肩/臂/躯干峰值归一化力矩、关节速度、左右手承重、局部摩擦、相对抓持、目标朝向、空间及底盘制动；区分静态、加速、制动阶段。静态/偏心失败或姿态筛选失败均如实记录，不自动弱化夹持或扩展扫描。

物理运行时只给执行器命令；IK及姿态筛选使用独立状态。模型和真实能力未标定的边界保持。

完成条件：至少获得可追溯的论文方法比较、理论映射核查、默认回归和有资格说明的物理结果；不要求优化一定提高性能。报告应解释哪些量可分配、哪些必须改变姿态才能变化，以及与急停课题的实际关系。源码和结果保存到当前项目，不更新个人知识库。

## 结果

首批16次完成后，发现偏心 QP 承重接近杠杆平衡可直接算得的60/40，因此追加几何分担静止/缓冲/半步长3次、最终代码默认回归2次，共21次。追加属于强基线小型验证，不新增依赖，不调整原物理参数。

- 4篇直接相关文献按摘要/方法原文分别记录。双臂分担及全身协调均有既有研究；没有把本轮适配写作论文复现。
- 21次均通过质量检查，18次运动均通过底盘制动；17次通过抓持，4次偏心对称失败保留。静止的制动判据在汇总中不适用。
- 偏心静止时对称最大相对变化2.748 mm、QP 1.701 mm、几何1.700 mm；缓冲QP 1.704 mm、几何1.703 mm。三方法半步长分类相同。有限6 s结果，仍漂移，未证明长期稳定。
- 原姿态到torso_2 +0.1 rad，缓冲制动的臂部最大归一化峰值30.11%→24.40%，躯干35.81%→45.34%；不是全身最坏负担改善，也不是运行中的主动躯干轨迹。
- 固定姿态的共同躯干内部扳手映射约1e−16；QP与独立SciPy的32个一般线性约束比较最大解差1.50e−7；16个盒KKT检查、30组抓取映射检查通过。
- 初版和最终默认固定/缓冲，均逐元素精确复现第九小节；运行快照/哈希已核验。最终QP与归档实现另作12个记录状态的兼容性检查。
- 仅分析工具的CSV读取补充了布尔状态解析，旧数值字段保持；未改旧模型、冻结基线或历史数据。
