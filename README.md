# Wheel-Based Dual-Arm Braking Research

This repository contains the planning records and simulation code for the
controlled-braking and payload-stability study of a wheeled dual-arm robot.

## Layout

- `docs/`: project plan, stage plans, and decision records.
- `simulation/rby1/`: MuJoCo model builders, stopping references, checks, and
  analysis scripts.
- `outputs/`: curated small reports and audit summaries. Large trajectories,
  rendered media, source PDFs, and local run logs are intentionally ignored.

The current research status is maintained in `docs/PROJECT_PLAN.md`. Generated
outputs are evidence snapshots, not a replacement for the source code or the
stage plans.
