# 联合制动路线与多指标持物稳定：首轮调查

日期：2026-11-01。范围：总体规划S1的定向调查；目标已确认，具体算法与后续实验尚未确认。本轮没有新增控制器、物理仿真或硬件验证。

总体入口：[PROJECT_PLAN](../../../docs/PROJECT_PLAN.md)。小节状态与执行记录见[S1计划](../../../docs/plans/32-s1-literature-and-integrated-stop-scope.md)。

## 1. 调查后的主要判断

用户的完整目标可以保留：危险触发后，根据障碍和当前状态，选择底盘制动路线与速度，协调腰臂姿态及受力，最终使整机和物体稳定停止。它是具有明确耦合关系的系统目标，工作量充足；单篇论文应从中找出一个可验证的核心增量，不能把每个模块都要求为新算法。

目前最值得检验的问题是：**在相同初态、障碍信息及运动/接触能力下，把可用停止空间、腰臂运动能力与抓持受力条件一起用于停止决策，相比合理适配的成熟方法，究竟改善哪些稳定指标、哪些可行工况，付出多少停止时间和计算代价？**

这仍是候选研究问题。已有前作覆盖联合避障、稳定运输、全身预测控制和双臂力适应，尚不能宣布创新成立。不能只因论文没有使用“急停”这个名称，就判断其方法不能适配。

## 3. 完整系统应怎样分解

建议将职责分成下面几层，算法尚不冻结：

| 模块 | 输入 | 输出与必须交换的条件 |
|---|---|---|
| 停止任务与环境 | 当前机器人/物体状态、障碍几何、停止请求、模型能力 | 哪些部位受限、仍可用的停止空间；首先接收已知几何，不同时研发完整雷达/建图系统 |
| 停止运动规划 | 上述空间、当前速度、腰臂与抓持可行条件 | 底盘二维路线及速度、物体位姿/速度参考、最终停止要求；不能只替底盘找一条无碰路径 |
| 全身运动与动力学执行 | 底盘/物体参考、反馈、关节与接触模型 | 腰臂关节运动、双手期望扳手、轮/关节控制量或硬件可接受命令 |
| 可行性反馈 | 跟踪误差、可达姿态、关节/接触负担、求解状态 | 把下层做不到的条件传回规划；避免规划与执行各管一段 |
| 多指标审计 | 实际整机/物体/接触记录 | 区分惯性负荷、抓持表现、避障可执行性与停车后稳定 |

目标停止状态应包括底盘、上身及物体进入静止持物，而不只是底盘速度归零。停止后的观察时长统一；残余物体运动和慢漂单独报告。终端容差和安全条件要有模型分辨率或任务来源，不能现在任意填数。

对于差速底盘，路线不是可以随意平移的曲线：它受滚动运动约束。转向时侧向加速度与速度和曲率相关，近似为a_n=v²κ（也可写vω）。所以绕开正前方障碍可能引入侧向抓持负荷，路线与速度应一起评估；这属于物理分析，不是本轮已经验证的性能结论。

## 4. 三种技术路线的取舍

| 候选 | 优点 | 困难与代价 | 当前定位 |
|---|---|---|---|
| A 全身动力学联合MPC | 可直接表达底盘、腰臂、物体与接触力的耦合 | 维度高、碰撞非凸、接触模型和初始化要求高；实时求解及失败处理工作大 | 保留为更充分耦合的候选，不立即重写 |
| B 任务/物体空间停止规划＋全身动力学执行 | 可以复用现有参考、运动映射、逆动力学和观测；职责清晰 | 必须向上反馈可行条件；否则上下层分别成功仍可能整机失败 | **当前推荐的总体候选**，具体MPC/QP/HQP等需下一节比较 |
| C 有限停止动作族＋连续调参＋几何/能力筛选 | 简单、可解释、适合作强基线与首个闭环 | 有限动作族不能代表所有可行路线；筛选失败不证明物理无解 | 先建立的成熟基线，不直接当最终贡献 |

以上代价是结构判断，不是经过本平台计时的工期结论。B有分层全身MPC的文献先例，推荐它是为了逐项验证和复用，不能据此宣称分层结构新颖。C若经合理适配已满足要求，应保留这一结果并重新讨论核心增量；只有具体证据说明层间割裂造成不足时，才有理由升级耦合程度。

## 5. “力矩分配”具体指什么

需要区分两件事：

1. **双手接触扳手/内力分配**：左右手各承担多少力和力矩，是否保持接触、摩擦可行，夹紧内力是否合适。
2. **关节驱动力矩与全身运动分配**：在相同物体任务下，腰、肩、肘等怎样运动，所需驱动力矩是否可执行。

前者不是把总力简单除以二，后者也不是任意把一个力矩从肩膀搬到腰上。物体运动先规定合力与合力矩需求，多余自由度才允许选择分担；机器人还必须满足自身动力学和运动限制。对作用在物体上的双手力f_i和接触力矩μ_i，以世界系、物体质心c计，刚体关系为：

Σf_i=m(a_o−g)

Σ[(p_i−c)×f_i+μ_i]=I_w α_o+ω_o×(I_w ω_o)

I_w是世界系质心转动惯量，p_i是接触作用点。这些是建模关系，不是新算法，也不保证接触一定不滑。若最终硬件只开放位置/速度或导纳接口，应按可用接口适配；不能把仿真里的力矩命令直接写成实机能力。

## 7. 稳定性怎样判断

不把所有量混成一个任意加权分数。先分组报告，再根据物体和可验证任务决定主指标：

| 组别 | 观测 | 必须防止的误读 |
|---|---|---|
| 物体世界运动 | 线/角加速度、jerk、姿态变化、参考误差、稳定时间 | 加速度小不能自动推出相对运动小 |
| 相对抓持 | 物体相对手的SE(3)变化、接触局部运动、接触保持 | 手坐标参考点变化、接触速度路程不等于材料点真实滑移 |
| 接触受力 | 每手力/力矩、负荷分担、摩擦利用与内力 | 合力变小不意味着每手更安全；夹紧预载也不能越小越好 |
| 安全与可执行 | 整机/载荷间距、关节范围/速度/力矩、轮地行为 | 规划无碰不能替代实际闭环轨迹无碰 |
| 停车后行为 | 统一时窗内物体/手速度、残余摆动、相对慢漂 | 对尚未消除的数值慢漂不做微米级防滑优越性排名 |

动力学、几何可执行性应与稳定收益一起验收：不能通过撞上障碍、无限推迟停止或任意提高夹紧能力换取较低加速度。未知摩擦或损伤阈值要标假设，不能当实物保证。

## 8. 后续顺序与要证明什么

本轮建议保持总体阶段S1→S2→S3→必要时S4，不另起一串临时实验。

**S1当前出口**：把这份首轮调查和候选路线交给用户/导师讨论。完整目标不再待选；推荐分层路线及单篇核心问题仍待确认。所需硬件接口和独立夹持验证资源仍未知。

**S2推荐先回答的关键问题**：现有模型能否可信地执行二维制动，并提供足以比较停止决策的运动、受力和抓持观测？先制定有限任务合同与资格预算，再做最小验证。它解决的是“实验台能不能检验完整目标”，尚不评价新算法优越性。

S2合同需要明确：差速滚动与控制权限、障碍/状态输入、静止持物终态、名义载荷与接触假设、哪些指标可以形成主张、失败分类。高速和距离应从经过检查的停止能力/任务需求中选取，不由本轮任意指定。先用静态已知几何和一类刚体载荷建立最小可检验任务，是实施阶段建议，不改变最终整体目标。

**S3随后证明**：在相同信息、控制权限、载荷和停止要求下，成熟动作族/连续调参及合理适配的前作究竟做到哪里。必须同时检查闭环运动与稳定指标。不同权限（给定底盘/可调底盘）分组报告。

**S4有条件研究的增量**：若S3显示腰臂/接触可行性未及时影响上层制动，且有独立可行参考，则讨论怎样把这些条件更有效地反馈进路线与速度选择。要对比收益、计算代价和失败边界，并再查对应文献；当前只是假设，不能预写成贡献。

最后区分三类失败：物理约束本来冲突、有限动作/近似模型没有覆盖、数值求解失败。后两者不能自动证明不存在安全停止动作，第一类也不能靠更复杂控制器保证解决。
