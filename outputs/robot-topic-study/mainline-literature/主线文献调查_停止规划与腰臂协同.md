# 急停末端控制主线：停止规划、反馈修正与腰臂运动分配

调查日期：2026-10-31。按用户要求先查论文，不运行新仿真、不实现新控制器；暂缓关节力矩饱和与重载极限支线。本文为定向调查，不是完整系统综述或新颖性保证。

## 一、调查后的判断

“触发时读取当前状态，生成平滑停车轨迹”“低频MPC＋高频执行”“移动底盘和机械臂共同规划”“双臂持物时全身运动分配”都有直接前作。主线可以继续，但不能把这些模块名称或简单组合当成创新。

当前值得缩小验证的问题是：**底盘必须执行给定制动要求时，如何利用上身有限的相对运动行程和方向性安全空间，从触发状态出发完成末端停止，并处理实际制动与预测不一致。**这是根据下面文献及本项目范围提出的候选问题，尚未证明未被其他论文覆盖。

本轮核对8篇文章。期刊/会议书目以Crossref及原始机构/出版商入口核对；方法以实际读到的版本为准。预印本和期刊版本合并为同一工作，分别标注阅读范围；补充视频、单图DOI不当作独立论文。

## 二、八篇论文分别解决了什么

### P1｜成熟在线轨迹生成：应优先作为强基线

Lars Berscheid、Torsten Kroeger，2021，*Jerk-limited Real-time Trajectory Generation with Arbitrary Target States*，Robotics: Science and Systems XVII。DOI：10.15607/RSS.2021.XVII.015。

给定初始/目标位置、速度、加速度和运动学限制，Ruckig生成多自由度同步的限jerk轨迹；速度接口可用于停车。“任意状态”仍有输入可接受性条件，不代表物理上任何状态都可满足全部限制。[论文](https://www.roboticsproceedings.org/rss17/p015.pdf)、[作者代码](https://github.com/pantor/ruckig)

可复用为停车参考基线，另加本任务的几何、空间和双臂可执行性核查。官方README把位置区间、Tracking等高级功能标为Pro，中间点的Community实现使用非实时云接口；不能把所有功能都视为免费本地急停能力。本轮未安装或运行。

阅读范围：PDF第2页III问题定义及IV算法关键部分，作者README输入验证、速度接口和功能边界。

### P2｜保持原路径的受控停车已有成熟研究

Friedrich Lange、Michael Suppa，2015，*Trajectory Generation for Immediate Path-Accurate Jerk-Limited Stopping of Industrial Robots*，ICRA，2021–2026。DOI：10.1109/ICRA.2015.7139463。

其方法用弧长参数保持路径几何形状，同时限制加速度与jerk；独立缩放各坐标在曲线路径上可能偏离原路径。论文含KUKA实验，所讨论的预警下受控停车与其使用的emergency-stop术语有区别。[作者全文](https://elib.dlr.de/96525/2/stop_ICRA15_header.pdf)、[机构书目](https://elib.dlr.de/96525/)

它适合“原搬运路径必须保持”的对照；不能据此推断物体接触稳定或既定底盘制动下的双臂相对运动也已解决。阅读了6页PDF的摘要、II/III、实验和结论，未核实可运行源码。

### P3｜停止轨迹可预测性也已有直接前作

Mazin Hamad等，2023，*Fast yet predictable braking manoeuvers for real-time robot control*，IFAC-PapersOnLine 56(2):9984–9991。DOI：10.1016/j.ifacol.2023.10.711。

用动力学模态及可行限制构造可预测制动，并以非线性最短时间控制作比较。所读模型假设包括局部准静态补偿、无外部接触力；仿真为7自由度臂中的3关节运动。[作者预印本v1](https://arxiv.org/html/2306.06525v1)

可借鉴停止距离预测与实际结果的比较口径；力矩能力是其重要部分，按用户要求本轮不将其作为主要实现路线。阅读范围为模型假设、方法概述及实验范围，未复现。

### P4｜液体急停：最直接的邻近工作

Samuli Hynninen、Ville Kyrki，2026，*Model-Predictive Spill-Free Emergency Stopping for Liquid-Manipulating Robots*，IEEE RA-L 11(11):12751–12758。DOI：10.1109/LRA.2026.3734909。

所读预印本v1采用摆模型、QP与软防溢出约束；20 Hz滚动规划配合高频执行，反馈机器人状态并用实际笛卡尔加速度更新液体状态。v1结论明确讨论了自由运动方向假设与受限空间扩展。[已读方法原文v1](https://arxiv.org/html/2604.16667v1)

它说明触发接管、反馈和MPC本身都不能作为我们的新贡献。须特别保留版本边界：[Aalto期刊记录](https://research.aalto.fi/en/publications/model-predictive-spill-free-emergency-stopping-for-liquid-manipul/)已列最终发表PDF与2026年11月刊书目，但本轮PDF访问403，尚未比对最终正文，故空间限制只能表述为v1的明确边界。不能据此宣布期刊最终版未处理相关问题。

### P5｜稳定运输MPC已经同时考虑物体与空间

Adam Heins、Angela P. Schoellig，2023，*Keep It Upright: Model Predictive Control for Nonprehensile Object Transportation With Obstacle Avoidance on a Mobile Manipulator*，IEEE RA-L 8(12):7986–7993。DOI：10.1109/LRA.2023.3324520。

其全身MPC联合规划底盘与臂，用jerk输入、物体接触约束和避障约束维持托盘运输；机器人有状态反馈，但不采用物体位姿在线反馈。它是非抓持托盘任务，且底盘可参与优化。[已读v2方法与附录](https://arxiv.org/html/2305.17484v2)

因此“物体稳定＋移动操作＋避障MPC”已有直接工作。对我们的公平适配，应明确把底盘自由优化改为给定制动输入，并替换托盘接触为本任务的抓持条件。[作者upright代码](https://github.com/learnsyslab/upright)已核查入口，尚未安装或复现。

### P6｜在线重规划未必天然更平稳

Adam Heins、Angela P. Schoellig，2025，*Robust Nonprehensile Object Transportation With Uncertain Inertial Parameters*，IEEE RA-L 10(5):4492–4499。DOI：10.1109/LRA.2025.3551067。

v3采用鲁棒质心接触约束，规划后再核查更广泛的物理可实现惯性；实验采用离线规划后跟踪，并报告在线更新可能增加末端振动。不能概括为在线鲁棒优化了全部未知惯性。[已读v3，V–VII](https://arxiv.org/html/2411.07079v3)

对本项目的直接启发是：必须比较“一次生成后跟踪”和“持续重规划”，检查新旧参考接管的连续性。其惯性鲁棒算法可后续再研究，本轮不扩展载荷极限。

### P7｜双臂移动机器人已实现任务规划与全身执行分层

Wenqian Du等，2026，*Efficient Whole-Body Model Predictive Control for Online Compliant Dual-Arm Mobile Manipulation*，Journal of Field Robotics，e70320，Early View。DOI：10.1002/rob.70320。

已读2024预印本v1：先规划双手任务运动，再优化全身关节轨迹，预测导纳把受力偏差转成运动修正；Bezier参数化用于保持位置/速度参考一致。它适配位置/速度接口，不能直接当作关节力矩WBC。[已读v1](https://arxiv.org/html/2410.22910v1)

可借鉴腰臂运动分配与上下层接口。2026年期刊发表信息和摘要由[出版社](https://onlinelibrary.wiley.com/doi/10.1002/rob.70320)核对，未比对最终方法全文，也未核实可运行代码。文中全身联合规划不等于已经验证本项目的指定底盘制动约束。

### P8｜双臂闭链与全身避障也不是空白

Silong Zhang等，2025，*Hierarchical Framework for Constrained Dual-Arm Cooperative Manipulation with Whole-Body Collision Avoidance*，IROS，5131–5138。DOI：10.1109/IROS60139.2025.11247571。

出版社摘要/引言描述了学习规划与经典控制分层，以保持双臂共同持物几何关系并全身避障。[出版社来源](https://doi.org/10.1109/IROS60139.2025.11247571)

本轮只核到摘要、引言和书目，不能确认其具体移动底盘/躯干构型或停车约束。它用于提醒：增加第二只手、闭链约束或全身避障本身不是创新。

## 三、对我们主线真正有用的区分

| 需要解决的环节 | 已有基础 | 本项目还必须具体处理的内容 |
|---|---|---|
| 触发状态出发的平滑停车 | P1/P2 | 不能默认触发时物体加速度为零；明确接管状态和运动方向 |
| 停止轨迹预测 | P3 | 底盘制动作为给定输入，预测与实际偏差须单独记录 |
| 物体稳定的预测控制 | P4/P5/P6 | 刚体抓持与液体/托盘的约束不同，不能只替换名称 |
| 腰臂共同执行末端任务 | P7，P8为背景 | 保持双手一致性，处理可用行程和全身包络；先验证运动学分配，力矩饱和暂缓 |
| 在线反馈是否值得 | P4/P5为正向方法，P6有反例 | 与一次规划后跟踪公平比较，并检查参考切换产生的振动 |

以上是基于阅读范围的机制映射，不是声称这些论文完全没有某个扩展，也不是完整覆盖全部相关文献。

## 四、建议收敛成的最小研究问题

在抓取已完成、底盘按给定要求受控制动、上身保持可控的条件下，能否在有限前向空间和缓冲行程内，从触发状态生成末端停止动作，并在实际底盘运动偏离预测时修正？

候选的关键耦合量是物体相对底盘的额外运动：

\[
\Delta r(t)=[p_o(t)-p_b(t)]-[p_o(0)-p_b(0)],\qquad
\dot{\Delta r}=v_o-v_b,\quad \ddot{\Delta r}=a_o-a_b.
\]

这里是本项目拟采用的模型关系，不是上面论文的新定理。物体的平滑停止不能只看自身参考，还要同时满足相对行程、手臂可执行路径以及物体/手臂的方向性安全包络。若底盘运动改由优化器自由延长，必须明确那已改变本任务要求。

第一版建议保持直线和物体朝向，使用已核验的有限工况，先固定躯干；把当前离线的空间/IK检查接到触发状态。底盘制动过程先已知，再加显式有界偏差。没有真实来源的物体加速度和姿态阈值只作参数，不包装成行业要求；接触慢漂保留为独立仿真边界。

## 五、下一实施阶段应怎样比较

| 对照/候选 | 目的 | 本轮状态 |
|---|---|---|
| 固定上身随底盘停车 | 统一底盘制动的基础对照 | 项目已有 |
| 现有三次/分段限jerk缓冲与离线准入 | 判断固定模板能做到哪里 | 项目已有，仍有原适用范围 |
| Ruckig停车＋任务空间/局部IK检查 | 成熟、状态驱动的强基线 | 本轮仅调查，未接入 |
| 相同约束下一次规划后跟踪 | 隔离优化参考本身的作用 | 候选，未实现 |
| 同一规划问题滚动更新 | 判断反馈能否抵消制动预测偏差，及是否引入振动 | 候选，未实现 |
| 同一物体轨迹的腰固定/腰臂分配 | 隔离运动分配的收益 | 候选，力矩极限不作准入前提 |

第一批问题可以在相同物理参数下改变触发速度/加速度、初始持物姿态、可用空间和底盘预测偏差。比较实际停车、物体加速度/朝向、额外行程、空间违反、计划/执行偏差、参考切换连续性及求解耗时。原有检查结果、超时、模型内不可行和求解器未找到解需分开记录。

简化的一维参考优化可用QP建立验证平台；纳入完整腰臂运动学或非线性接触约束后，不应继续称整个问题为同一个凸QP。先不锁定完整NMPC或两层MPC，更不以增加优化器复杂度作为工作量和创新的替代。

## 六、建议与证据边界

本轮支持继续主线，但建议将“先自己写QP，再改成MPC”的顺序调整为：**先接入成熟状态驱动停车基线，明确其在本任务约束下能做到哪里；再决定是否需要受约束规划、反馈修正和腰臂分配。**这属于待讨论的实现建议，不是已授权的新算法实现。

候选贡献应落在既定底盘制动、有限相对行程、方向性空间和执行偏差之间的处理及证据上。任意状态、MPC、高频跟踪、腰臂分层均有前作；本轮不能证明其组合尚无人研究。若成熟方法经公平适配已满足目标，应缩减创新主张。
