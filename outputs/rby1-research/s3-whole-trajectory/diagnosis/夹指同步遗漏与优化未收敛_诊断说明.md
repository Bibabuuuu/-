# 夹指同步遗漏与优化未收敛：已有日志诊断

2026-11-02。状态：本轮诊断已完成；补回同步关系的场景副本只通过静态检查，尚未做修复后物理运行。无新优化求解、无新物理步进，S3仍累计31次68211步。

## 1. 首要发现：生成研究模型时漏掉了官方的夹指同步关系

冻结的官方MJCF文件rby1_v1.2.xml第236–239行有两项关节等式，分别约束左右夹爪：

```xml
<joint name="right_finger" joint1="gripper_finger_r1" joint2="gripper_finger_r2" polycoef="0 -1 0 0 0" />
<joint name="left_finger" joint1="gripper_finger_l1" joint2="gripper_finger_l2" polycoef="0 -1 0 0 0" />
```

在当前零参考关节位置下，它们表达q₁+q₂=0。结合两指的局部轴及安装姿态，两指会等量反向移动，开合时夹持中心固定。这里恢复的是指间同步，物体仍是自由刚体，通过接触被抓持；不是把物体焊接到手上。

本地官方源来自rby1-sdk提交`300a585c297d1bdf8554312c3a1659610a9823f5`；本轮重新核对其SHA256与原下载清单一致。研究模型的build_model.py从头构造MJCF树，读取了原模型的几何资源，但没有转移equality部分，当前场景neq=0。这是我们构建研究模型的遗漏，不能归为已证明的MuJoCo求解器错误，也不能继续把由它产生的漂移当作实体夹爪必然行为。

证据：[冻结官方源文件](../../../../work/robot-model-audit/sources/rby1-pinned/models/rby1a/mujoco/rby1_v1.2.xml)、[模型构建代码](../../../../simulation/rby1/build_model.py)、[来源与静态审计](finger_source_audit.json)。本轮网页工具未成功获取该固定提交的raw文件；来源结论基于本地冻结文件及下载清单哈希，不声称重新在线获取成功。

## 2. 为什么这个遗漏恰好产生了约0.13 mm的新增位移

当前每个指关节单独使用速度型执行器，增益125 N·s/m，被动阻尼5 N·s/m；闭合命令分别为+0.035和−0.035 m/s。执行器没有位置恢复项。这与[MuJoCo velocity执行器定义](https://mujoco.readthedocs.io/en/stable/XMLreference.html#actuator-velocity)的固定增益及速度反馈形式一致，具体数值也用编译模型和实际广义驱动力逐点核对。

两指的“相互靠近”受到物体接触阻挡，可以形成夹紧力。但缺少同步关系后，还留下了一个“两指保持间距、一起平移”的运动自由度。速度反馈能抵抗这一运动，却不会像位置约束那样把夹持中心拉回原处。

侧移动作停止后，夹持法向相对水平倾斜约0.636°，重力在该方向上的分量约0.109 m/s²。物体和指垫因此能以很小的速度一起移动。原动作基本水平，这个重力分量接近零。

为分清“物体相对手掌移动”和“物体相对指垫移动”，本轮从保存的关节位置重建指垫中心，逐点核对原观测。共同停车窗仍为[0.899862545,1.899862545] s：

| 新动作，1 ms步长 | 左手 | 右手 |
|---|---:|---:|
| 物体相对手TCP的X净位移 / mm | −0.132205 | +0.133433 |
| 两指垫中心相对手TCP的X净位移 / mm | −0.132210 | +0.133443 |
| 物体相对指垫中心的X净变化 / mm | +0.00000424 | −0.00000979 |
| 两指垫中心间距变化 / mm | +0.00000183 | +0.00000194 |
| 实际夹指中心平均X速度 / (mm/s) | −0.132209 | +0.133442 |
| 受力平衡估算的平均X速度 / (mm/s) | −0.132177 | +0.133409 |

物体与指垫中心几乎同步移动，开口宽度基本不变；这一部分主要是夹指中心相对手掌漂移，不是物体穿过夹指表面的法向滑移。半步长和另一只手均保持这一关系。停车窗中物体相对指垫中心的法向变化最大不超过约1.33×10⁻⁵ mm，远小于约0.13 mm的整体运动；这里只比较仿真数值，不把纳米级差异当实物测量精度。

对应的准静态受力平衡为：

\[
\dot x_c\approx\frac{m_f g_x-F_{o,x}}{2(k_v+b)}.
\]

其中x_c为指垫中心在手坐标中的法向位置，m_f是两根手指的总质量0.06653998 kg，F_{o,x}为该手对物体的接触合力在此轴上的分量。共同模式中两个相反速度命令的恒定项抵消，分母为2(125+5)=260 N·s/m。代入保存的接触力，可得到上表速度；忽略残余惯性的速度估算与实际速度的RMS差约0.000084–0.000089 mm/s。仅用每手一半载荷的重力近似，也预测约±0.1327 mm/s。

这条证据链支持“同步遗漏＋速度型夹指＋终态轻微倾斜”对新增法向漂移的解释。恢复同步后的反事实对照尚未运行，因此尚不能宣布漂移已经修好。竖直方向约0.156 mm/秒的原有慢漂也没有由本次诊断自动解决；它仍表现为物体相对指垫的切向运动，具体物理/数值含义继续保留原边界。

## 3. 优化未收敛：确认了什么，仍不知道什么

两项旧SLSQP都以40次迭代上限退出。根据[与本地版本系列对应的SciPy说明](https://docs.scipy.org/doc/scipy-1.17.0/reference/optimize.minimize-slsqp.html)，迭代次数、差分步长和终止精度是不同设置；达到迭代上限不等于已满足约束和最优性。原搜索记录没有保存逐迭代回调及KKT乘子，本轮不能追溯唯一失败原因或证明驻点。

本轮没有重新求解，只重算10个已保存代表点及三个点的局部差分，总计250次冻结参考回调，约7.40 s。所有重算的最小约束值与原记录一致。按原实现拆分约束后：

| 原记录中的点 | 主要未通过项 | 含义 |
|---|---|---|
| RMS已选评价365 | 无 | 原执行候选仍满足当时的参考合同 |
| RMS末条评价2833 | 双手导出的物体加速度分量不相容 | 最差分量约0.00016382 m/s²，原允许值约0.00015043；其障碍间隙仍满足条件 |
| 力矩末条评价2874 | 双手加速度相容性、物体障碍间隙、力矩上界 | 最差加速度分量约0.00016664 m/s²；参考间隙少约0.000812 mm；力矩上界还有归一化约0.00358的违反量 |

这些是规划中的数值相容性要求，不是测到机器人受力超过能力。力矩目标末段虽然预测力矩很小，但加速度RMS升至约1.95 m/s²，且未通过约束，不能作为有效改进。当前方案没有将夹指同步作为优化变量，因此同步遗漏与SLSQP失败是两个不同问题；恢复同步不自动让优化器收敛。

进一步核查发现：

- **局部近似与真实非线性有明显差异。** 两次搜索的首个大试探点，按种子处前向差分线性模型看，双手闭合约束只在约1e−12浮点范围内触边；代入真实运动学后，最大归一化违反量分别约101.6和1.83。直观地说，每个关节单独用平滑曲线改动时，两只手对同一物体的运动关系很容易在较大一步之后不再相容。这只是首个试探点，SLSQP还会做线搜索，不能单凭它断言算法设计错误。
- **所查导数没有明显错误信号。** 三个保存点、两种方向、三档中心差分步长，与当前前向差分Jacobian的闭合方向导数相对L2差约1e−8至1.3e−7。该有限检查不覆盖所有方向和全部约束，也不证明导数绝对无误。
- **约束存在大量相互关联及尺度差异。** 45个时刻形成4860个运动学不等式；闭合Jacobian的数值秩随姿态和阈值改变，初始点在相对1e−6阈值下为18，移动点为41/49。归一化约束行的梯度范数仍跨多个数量级。它们是优先诊断求解过程的证据，不足以证明某一个尺度设置就是唯一原因。

因此，当前合理结论是：严格双手相容性的非线性约束确实限制了搜索，末段仍未恢复合格；尚不能称任务不可行，也不宜直接放宽相容性条件、提高迭代预算或把失败包装为研究创新。约束数值化、可行性恢复和较小局部改动是后续候选，需要在基础模型修正后单独评审。

## 4. 已经准备的修复草案，以及尚未实施的部分

[候选场景副本](synchronized_scene_candidate.xml)只补回上述两个官方关节等式。去除新增equality节点后，XML树与原场景完全一致；编译后neq从0变为2，nq/nv/nu不变，质量、惯量、碰撞几何、接触参数、阻尼、执行器增益和限值均逐值相同。相同qpos下全部几何位置也逐值相同。

旧触发初态的最大q₁+q₂残差约0.000448 mm，远小于运动结束后的残差。只做手指最小投影使q₁+q₂=0，单指最大调整约0.000224 mm；速度也应按同一关系投影。投影保留开口宽度，其他关节、物体、底盘状态不变。投影只是初态准备，不能在运行中强行改qpos或锁住物体。当前没有保存或执行新的初态，没有覆盖旧模型。

**建议下一步先修复夹指同步，并完成有限回归，再处理优化求解。方案状态：待确认，尚未执行。**

1. 保留旧模型/数据；以草案副本为新版本，明确仅恢复两指关节同步、不增加物体约束。为执行器增加可选的显式初态入口，默认行为不变；旧执行版本先保存快照。
2. 用同一旧动作完成一次默认入口逐值回归，确认新入口没有改变旧路径。新模型采用上述最小投影的共同初态，报告状态差异和初始接触瞬态，不复用旧初态的平衡资格。
3. 固定原底盘和原侧移参考，不重新优化、不改障碍/摩擦/夹紧速度；先重查参考和几何，再运行同步模型下两条动作。需要时仅追加这两条动作的半步长配对。最多5次、13300步（回归1900＋两条主运行3800＋两条半步长7600）；任何模型/初态/几何资格失败即停止本批，不通过调参追加解救。
4. 重新比较TCP相对位移、指垫中心运动、物体相对指垫切向运动、手部受力、加速度、间隙及初始接触。检查同步误差受控且新增整体漂移是否消失，同时检查有没有新的过大接触力或跟踪恶化。只有这些数据出来，才能重新判断侧移动作的持物收益。

此修复来自明确的官方源遗漏，不需要先自创夹指中心位置增益。另一选择是在旧独立夹指模型中增加中心反馈，能抑制漂移，但会引入新的控制假设及调参；当前优先级低于恢复已有同步关系。完整实机夹爪动力学标定仍不在本轮范围。
