# 连续共享物体参考、初值接续与联合变量：方案评审

2026-11-02。**状态：只读调查已实现、已验证；连续适配及50参数联合规划仍为待讨论候选。** 用户同意在上一轮有限映射之后明确连续接口、初值合同与公平对照范围。本轮只做保存触发状态的运动学/Jacobian与基函数秩核查，零新IK、QP、外层求解和物理仿真。S3累计仍52次125061步，S4待开始。

## 1. 本次查清了什么

上一轮已证明：在旧RMS参考的声明节点上，一条物体运动可以映射为双手相容的关节位置、速度和加速度。但“参考内部相容”与“触发瞬间精确接上真实状态”是两件事。

这次直接读取原保存qpos/qvel，不做物理步进，也不修改任何初态：

| 观测 | 结果 | 含义 |
|---|---:|---|
| 物体实际竖直速度 | −0.0001561355 m/s，即−0.15614 mm/s | 触发状态中已经存在向下慢移，旧参考竖直速度为0 |
| 双手按各自刚性抓持推算的COM竖直速度 | 左−2.438e-8、右−3.313e-8 m/s | 双手运动与物体实际运动并非严格刚性一致；本次未判定其全部接触机理 |
| 物体实际前向速度与旧参考差 | 参考减实际约−7.095e-5 m/s | 旧参考初始条件也未完整保留物体实际平移速度 |
| 双手推算的物体速度差 | 线速度最大3.725e-7 m/s；角速度最大5.802e-6 rad/s | 不是精确零，但按原双手速度容差最大归一0.006226，小于1 |
| 上身旧参考与保存初速度最大差 | 5.49037e-5 rad/s | 上轮所报初速接续差异得到复核 |
| 底盘轮轴侧向实际速度 | 6.184e-9 m/s | 原平面无侧滑参考近似成立，不是精确所有分量接续 |
| 轮轴实际偏航角速度与旧参考差 | 旧参考0，实际−3.2805e-6 rad/s | 平面参考未精确继承这一微小分量 |
| 初始物体COM位置差 | 约2e-16 m以内 | 此处主要是速度接续差，不能误说初始位置装配错误 |

原上身初始q逐值一致。物体COM速度另用自由关节速度与“ω×质心偏置”公式复核，与Jacobian结果误差约2.71e-20 m/s；角速度误差约2.65e-23 rad/s。完整数值及来源哈希见[只读审计](initial_state_and_basis_audit.json)，入口为[审计脚本](initial_state_and_basis_audit.py)。

**结论边界：** 精确保持实际机器人全部初速度、实际物体初速度，并同时强制无相对运动的刚性抓持，会在当前初态产生不相容。本次证据不说明需要增加夹力/摩擦，也不把它算作新映射引入的错误。前面接触静止诊断的解释仍保留；不能把实际初态投影到刚性流形后当作原状态。

## 2. 初值接续的三个选项

| 选项 | 收益与代价 | 本阶段建议 |
|---|---|---|
| A：隔离数值核验继续沿用旧名义参考边界；实际保存状态不变 | 最小改动，便于只判断参考表示和计算成本；继承已有初速差，因此不能声称真实无缝接管 | 推荐用于下一轮接口资格，所有对照同样披露差异；不因此准入物理执行 |
| B：在参考侧建立显式相容速度投影/过渡 | 可以量化投影误差与接续代价；精确匹配哪些状态、误差度量及过渡约束是新关键选择 | 待后续单独讨论；不投影物理qpos/qvel |
| C：参考或执行层纳入接触顺应/相对运动过渡 | 更适合描述当前已有慢移；需要模型、估计、误差状态或力闭环依据，范围明显更大 | 本轮不实施，不能用随意降低刚性容差代替 |

A只是隔离基准的边界选择，不是最终接续解决方案。任何后续新物理候选都仍需独立处理实际初态及执行准入。

### 3.1 50参数候选的准确含义

固定原T≈0.619520703 s，只为第一轮隔离比较。采用已有8控制点五次基，初始位移/速度/加速度为零、终端速度/加速度为零，5行边界矩阵秩为5，故每个标量剩3系数；终点位置不强行锁定。只读重算边界残差约1.57e-14。

| 候选变量组 | 系数数 | 含义 |
|---|---:|---|
| 底盘纵向速度 | 4 | 复用已验证的C1分段三次速度基，不退回已受限的旧纵向基 |
| 底盘偏航角速度 | 4 | 复用原五次角速度修正及其积分 |
| 物体COM平移修正 | 3×3＝9 | 围绕旧物体参考的世界系平移 |
| 物体旋转修正 | 3×3＝9 | 围绕旧姿态的SO(3)局部旋转 |
| 上身冗余坐标修正 | 8×3＝24 | 固定初始N0，允许腰臂冗余随时间变化 |
| 合计 | 50 | 底盘、物体、冗余同时开放的局部候选 |

只开放前4组是26系数的**固定冗余受限基线**，不能称完整腰臂联合规划。50也不是对原68系数进行无损消元的证明；新旧连续函数族未证明包含关系，比较时必须同时披露表示族、原物理允许范围和计算代价。不能以“68变50”直接宣称更优或更快。

数值缩放建议沿用底盘0.1 m/s、0.3 rad/s和上身0.1 rad，物体平移0.01 m、旋转0.1 rad；这些仅是坐标量纲缩放，不是新增物理许可或运动幅度上限。实际仍检查原速度/加速度/jerk、航向、关节、障碍及自碰撞约束。

### 3.2 旋转和冗余的导数合同

候选定义R＝Exp(η^)R_seed，采用世界系角速度。令E＝Exp(η^)、ω_E＝J_l(η)ηdot，则：

- ω＝ω_E＋Eω_seed；
- α＝J_l(η)ηddot＋J_l_dot(η,ηdot)ηdot＋ω_E×(Eω_seed)＋Eα_seed。

不能把ηdot直接当ω，尤其不能漏掉随时间变化的种子姿态项。指数映射左Jacobian的定义和世界系左扰动关系核对自[GTSAM官方SO(3)文档](https://borglab.github.io/gtsam/so3/)；以上复合曲线导数为本方案按该约定推导，后续须用独立矩阵时间差分核验。复用现有SciPy/NumPy，不安装GTSAM。

冗余使用N0ᵀ(q−q_nom)＝ζ；其一、二阶分别为N0ᵀ(qdot−q_nom_dot)＝ζdot和N0ᵀ(qddot−q_nom_ddot)＝ζddot。N0在一个已冻结候选族内保持常数；若日后采用随时间变化的零空间，须补齐Ndot/Nddot项，不能静默替换。

N0拟直接读取上一轮reference_samples.npz中已冻结的N，避免每次重算SVD的符号/基选择改变坐标含义。50系数按v、角速度、COM平移xyz、旋转η的xyz、N0的8列顺序排列；各后三组每标量的3系数按行存储。具体身份与顺序见proposal.json。

共享物体抓持目标始终按COM偏置[0,0,−0.064] m转换到手目标。位置IK、速度及加速度来自同一组20方程，复用已验证Jacobian/Jdot路线。[MuJoCo官方Jacobian接口](https://mujoco.readthedocs.io/en/stable/APIreference/APIfunctions.html#mj-jac)规定点附着于指定刚体，且JacDot需要按顺序更新kinematics、comPos、comVel。这里不新增控制器或接触逆动力学。

## 4. 连续查询接口合同（候选）

复用现有WholeBodyStopReference的base/payload/joint回调；新建隔离适配器，先不改正式执行入口。

1. 对任意合法查询t，根据同一候选和解析基函数生成底盘、物体与冗余目标，再求解局部q/v/a；不对之前离散IK节点的关节q做简单插值来冒充连续相容。
2. 参数向量、模型/抓持版本、N0/种子身份和时间共同决定结果。缓存不可跨候选混用；第一次查询可在任意时刻，不能依赖调用顺序。先用确定性的q_nom(t)作IK种子；续接热启动只有在证明结果不依赖查询顺序后再考虑。
3. 底盘位置由v及积分得到的航向确定。积分面板从已冻结分段点划分，不随调用者给的一批采样点改变，以免batch和单点查询得到不同参考。
4. 输入不合法、局部分支失败、非有限数或预算耗尽均显式失败并记录；不悄悄返回旧参考、裁剪曲线或投影真实状态。矩阵条件数作为数值诊断报告，不伪装成新的硬件安全阈值。
5. t<0只钳制到初始参考值，不声称负时间区间的导数相容或触发前物理预测。T后的物体/关节和底盘位置姿态保持、速度/加速度为零；必须检查t=T连续性。
6. 零参数对应旧底盘/物体参考经已验证共享映射后的关节曲线，不保证关节q逐值等于原近似闭合曲线；上轮差异已经量化。
7. 接口形式校验不代替原始初速接续、密集几何、接触动力学或实际执行资格。
